Mark Russell Alerts: terms

These terms apply to the text messages of Mark Russell Alerts.

The program

Mark Russell Alerts is a one-way text alert program of Mark Russell, a sole proprietor. A self-hosted alert service sends short notices to the phone of the owner: severe weather warnings for the area of the owner, outages of the home services of the owner, and failures of the software jobs of the owner. The program sends no marketing and no promotions.

How to opt in

Text START to +1 (844) 844-2406. The number replies with a confirmation. The page how to opt in shows the full flow.

Frequency

Message frequency varies with events. Most days have 0 to 5 messages.

Cost

Message and data rates can apply. Your mobile carrier sets these rates.

How to stop

Text STOP to +1 (844) 844-2406 at any time. You get one last message that confirms the stop, and then no more messages. To start again, text START.

Help

Text HELP to +1 (844) 844-2406 for help. For other questions, use the contact on the GitHub profile of Mark Russell.

Carriers

Mobile carriers are not liable for delayed or undelivered messages.
